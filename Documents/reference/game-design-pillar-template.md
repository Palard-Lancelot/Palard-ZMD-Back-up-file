> **填表说明**
> - 这份文档只回答一个问题：**"这个游戏凭什么好玩，且凭什么让人玩第 100 局？"**
> - 只写"断言 + 理由"，不写实现细节（实现细节属于技术设计文档）。
> - 每一条都要能被**证伪**。"手感要好"❌ → "攻击后摇可被冲刺取消"✅
> - 全文控制在 2 页内。写不满不是问题，**写不具体才是问题**。
> - 每次动代码前先读一遍。改玩法先改这份文档，再改代码。

## 1. 设计支柱（Design Pillars）⭐ 核心中的核心

**定义：3 条不可妥协的原则。** 任何新功能、新美术、新道具，如果违反其中任何一条，就砍掉。

每根支柱必须包含：**名称 + 一句话主张 + 它禁止了什么**。

> **示例（仅供参考，不要照抄）**
> - 支柱1「每一击都有重量」：攻击必须有顿帧、击退、屏震。**禁止**瞬发无反馈的伤害。
> - 支柱2「死亡是学习，不是惩罚」：**禁止**任何无法通过玩家技巧规避的伤害。
> - 支柱3「Build 决定打法，而非数值」：**禁止**纯 `+10% 攻击力` 类的道具设计。

## 2. 核心循环（Core Loop）

按"秒 → 分 → 局 → 跨局"四层各写一遍，每层都要有**明确的决策点**（没有决策的循环不是游戏）。

| 层级 | 时长 | 循环内容 | 玩家在此做的**决策** | 反馈/奖励 |
|---|---|---|---|---|
| 微循环 | 1–5 秒 | 观察 → ____ → ____ | | |
| 房间循环 | 30–90 秒 | 进入房间 → ____ → 离开 | | |
| 单局循环 | 20–40 分钟 | 开局 → ____ → ____ → 死亡/通关 | | |
| 元循环 | 数小时 | 死亡 → ____ → 再开一局 | | |

**循环自检**：
- [ ] 微循环在没有奖励的情况下，单纯操作是否也爽？（动作游戏必须"是"）
- [ ] 单局循环是否每 2 分钟就给一次有意义的抉择？
- [ ] 元循环是否让"失败的一局"依然推进了某样东西？

## 6. 手感规格（Feel Spec）——横板动作游戏的生死线

**把这些数值先定一个"感觉对"的初始值，然后在游戏内做成可实时调节的参数。**

| 参数 | 初始值 | 说明 |
|---|---|---|
| 重力 | | |
| 最大下落速度 | | |
| 跳跃高度 / 滞空时间 | | |
| 土狼时间（Coyote Time） | ~0.1s | 离开平台后仍可跳的宽限 |
| 跳跃缓冲（Jump Buffer） | ~0.1s | 落地前按跳会被记住 |
| 移动加速度 / 减速度 | | 横板游戏忌讳"立即到最大速度" |
| 攻击前摇 / 有效帧 / 后摇 | | |
| 后摇可取消窗口 | | |
| 受击无敌帧 | | |
| 受击击退距离 / 硬直 | | |
| 顿帧（Hit Stop）时长 | ~0.05–0.1s | 打击感第一功臣 |
| 屏幕震动 幅度 / 时长 | | |
| 输入延迟上限 | < 50ms | 超过就是"手感差" |

**取消规则（Canceling）—— 手感高级感几乎全在这里：**
- 攻击后摇可被 → 冲刺 / 跳跃 / 下一次攻击 取消？____
- 跳跃可被 → 攻击取消？____
- 受击硬直是否可被输入打断？____

## 8. 明确不做什么（Non-Goals）⭐ 和支柱同等重要

| 不做 | 理由 |
|---|---|
| 例如：多人联机 | 网络同步会吃掉全部工期 |
| 例如：剧情分支 | 与核心循环无关 |
| 例如：程序化美术 | 风格不可控 |
| 例如：手机端适配 | 首发只做 PC |
| | |

> 这份列表每加一项功能就回来看一眼。**项目烂尾通常不是因为想不到要做什么，而是因为什么都想做。**

## 10. 成功标准（Definition of Success）

**用可测的方式写，不要写"好玩"。**

| 阶段 | 通过标准（可证伪） |

| 手感验收 | 盲测玩家能说出"打击感好"而非"还行" |

| 个人目标 | （例如：能完整发布，不烂尾） |

## 11. 风险登记（Risks）

| 风险 | 概率 | 影响 | 缓解方案 |
|---|---|---|---|
| 内容量爆炸，做不完 | 高 | 高 | 先做垂直切片，规模清单×1.3 后砍 30% |
| 关卡生成出现不可通关 | 中 | 高 | 生成器加约束 + 自动化验证脚本 |
| 道具组合产生数值崩溃 | 中 | 中 | 标签系统 + 伤害上限封顶 |
| 手感调不出来 | 中 | 致命 | 第一天就做好实时调参面板 |
| 美术风格不统一 | 中 | 中 | 先锁定一套参考图与色板 |
| 动力丧失 | 高 | 致命 | 每 2 周出一个可玩版本 |
