# 20 周单人开发计划 — 横板 2D 肉鸽

> 前提：**1 人全职 20 周**。若每周只能投入 10 小时，把下面所有数字乘以约 4
> （即相当于 5 周全职），能做的量要按"砍到能做的版本"再砍一半。

---

## 0. 工时预算（先算这个，再谈内容）

```
总工期              20 周
× 70% 可用率        = 14 周  ← 真正能用来"产出"的时间
预留 30%            =  6 周  ← bug / 返工 / 集成 / 打磨 / 生病
```

**为什么是 70%**：经验值。新项目里 bug 修复、系统集成、返工占总工时 25–35%。
如果你觉得 70% 太保守，可以试 80%，但**第一次做游戏的人几乎一定超支**。

### 14 周怎么分

| 分类 | 工时 | 说明 |
|---|---|---|
| 系统架构 | **5.0 周** | 状态机、战斗框架、道具系统、存档 |
| 关卡生成器 | **2.0 周** | 预制房间 + 校验重试 |
| 内容（美术/敌人/Boss/关卡） | **5.0 周** | 见下方清单 |
| UI + 音频 | **1.0 周** | 4 个界面 + 20 个音效 |
| **小计** | **13.0 周** | |
| 手感调参 | **1.0 周** | ⚠️ 见下方警告 |
| **合计** | **14.0 周** | |

> ⚠️ **1 周调手感是不够的。** 真实情况是手感调参**分散在全程**，不是一个阶段。
> 这里单列 1 周是为了提醒你"它会吃掉时间"，实际应从每周挤 2–3 小时做。

## 2. 20 周排期（垂直切片路线）

核心策略：**先做一条能跑通的窄链路，再横向加内容。**
每周结束必须有一个"能玩"的版本。

| 周 | 目标 | 交付物（可玩） | 里程碑 |
|---|---|---|---|
| **W1** | 引擎熟悉 + 项目骨架 | 目录结构、Git、`.gitignore`、输入映射 | |
| **W2** | 玩家移动 | 走/跳/落，带土狼时间 + 跳跃缓冲 | |
| **W3** | 调参面板 | `FeelConfig` Resource + 运行时滑块 | ✅ **手感可调** |
| **W4** | 玩家状态机 + 攻击 | 3 段连击、命中判定、顿帧、屏震 | ✅ **打空气也爽** |
| **W5** | 受击 + 冲刺 | 受击硬直、无敌帧、冲刺（含无敌） | ✅ **能被打能躲** |
| **W6** | 敌人 AI 框架 | 1 种敌人（冲锋兵），有攻击前摇 | |
| **W7** | 战斗闭环 | 打死/被打死/重生 | ✅ **最小战斗循环** |
| **W8** | 道具系统 | 数据驱动 3 件道具，可拾取生效 | |
| **W9** | 房间切换 | 单房间 → 门 → 下一房间（固定序列） | |
| **W10** | 存档 + 单局状态 | 血量/道具/层数持久化，死亡重开 | ✅ **20 分钟能玩** |
| **W11** | 房间生成器 | 校验重试算法，12 块模板接入 | |
| **W12** | 三选一 + 出口选择 | 战利品浮现界面、双出口分叉 | ✅ **有 roguelike 味** |
| **W13** | 敌人扩充 | 加远程兵 + 跳跃兵 | |
| **W14** | Boss | 1 个两阶段 Boss | ✅ **能通关** |
| **W15** | 元进度 | 死亡结算 + 解锁（替换初始武器） | |
| **W16** | UI 收尾 | 标题、设置、音量、按键提示 | |
| **W17** | 音频接入 | 20 音效 + 2 BGM | ✅ **内容完成** |
| **W18** | 美术替换 | 色块 → 真实动画（玩家 + 3 敌人） | |
| **W19** | **手感打磨周** | 集中调参、打击感、节奏 | |
| **W20** | 收尾 + 打包 | 导出 exe、修 bug、写说明 | ✅ **可发布** |

**注意 W18 之后才是真实美术。** 前 17 周全部用色块占位 —— 这不是偷懒，
是**唯一能让你在美术上不浪费时间的顺序**。手感没定就画动画，等于白画。

## 3. 为了 20 周，砍掉什么

对照完整版（约 87 人周），20 周版砍掉了 **83%**。砍清单：

| 砍掉 | 省下 | 理由 |
|---|---|---|
| **Biome 从 3 个 → 1 个** | 8 周 | 最高优先级可砍项。1 个 Biome 做深 > 3 个做浅 |
| **道具从 20 件 → 6 件** | 7 周 | 配合"效果原语"进一步降本 |
| **Boss 从 2 个 → 1 个** | 3 周 | 第 2 个 Boss 是纯增量，不影响验证核心 |
| **敌人从 6 种 → 3 种** | 3 周 | 行为差异够用 |
| **玩家动画 3 套武器 → 1 套** | 4 周 | 武器靠特效和数值区分，不靠动画 |
| **元进度天赋树 → 线性解锁** | 3 周 | 只保留"解锁新初始武器" |
| **每日挑战 / 成就 / 图鉴** | 2 周 | 全砍，发售后再说 |
| **剧情 / 叙事** | — | 不与任何支柱绑定 |
| **多人联机** | — | 吃掉全部工期 |

### ⚠️ 绝对不要砍的两项

| 不砍 | 理由 |
|---|---|
| **调参面板（W3）** | 它是后面 17 周所有手感工作的前提。砍了它，W19 那一周会变成三周 |
| **bug 预留 6 周** | 砍掉它 = 承诺 100% 效率，不可能实现 |

## 4. 6 件道具怎么做（关键技术决策）

**不要每件道具写一套逻辑。** 用「效果原语」组合：

```
原语（10 个，代码只写一遍）：
  吸血 / 连锁 / 爆炸 / 减速 / 反弹 / 召唤 / 穿透 / 暴击 / 位移 / 护盾

6 件道具 = 原语的组合配置（.tres 资源，不写代码）：
  血刃     = 吸血 + 暴击
  雷刃     = 连锁
  冰霜匕首 = 减速 + 穿透
  爆裂锤   = 爆炸 + 位移
  荆棘盾   = 反弹 + 护盾
  影分身   = 召唤 + 位移
```

**收益**：新增道具从 0.5 周降到 **0.1 周**（只是填个资源文件）。
**代价**：需要提前设计原语接口（约 1 周），且原语之外的效果做不了。

对 20 周的项目，这个取舍**必须做**。

## 5. 12 块房间模板的配置

校验重试生成器需要足够的池子，否则反复重试会失败或产出单调。

| 类型 | 数量 | 作用 |
|---|---|---|
| 战斗房（小） | 4 块 | 主体，1–2 敌人 |
| 战斗房（大） | 3 块 | 3+ 敌人，逼走位 |
| 宝箱房 | 2 块 | 三选一所在地 |
| 商店房 | 1 块 | 资源兑换 |
| 入口房 | 1 块 | 每层起点，固定 |
| 出口房 | 1 块 | 每层终点，固定 |
| **合计** | **12 块** | |

**约束（生成器必须满足）**：
1. 入口到出口必有路径
2. 宝箱房不在相邻节点连续出现
3. 每层至少 2 个道具选择点
4. 商店房每层恰好 1 个
5. 房间必须属于当前 Biome 主题（20 周版只有 1 个主题，此条免检）

## 7. 20 周结束时你会有什么

**有的：**
- 1 个可玩、可通关、可重开的横板 2D 肉鸽
- 手感接近 Dead Cells 的**移动与战斗**（这是最大资产）
- 1 个 Biome、3 种敌人、1 个 Boss、6 件道具、12 块房间模板
- 校验重试生成器（可复用，加内容即可扩展）
- 导师/MVP 级别的作品集项目

**没有的：**
- 商业级内容量（Dead Cells 是 11 人 × 数年的量）
- 多 Biome、深构筑、天赋树、每日挑战
- 完整美术（可能是色块 + 部分动画）

**这不是失败。** 20 周的合理目标是**验证核心循环是否成立**，不是做完一个商业产品。

## 8. 三个判定节点（到点就做决定）

| 时间点 | 判定问题 | 否则 |
|---|---|---|
| **W7** | 打死敌人、被打死、重生，**单纯操作爽吗？** | 不爽 → **停下，只调手感，不加任何内容** |
| **W10** | 连续玩 20 分钟，**想再来一局吗？** | 不想 → 检查核心循环的决策点是否太少 |
| **W14** | 能通关了吗？ | 不能 → 砍掉元进度和美术替换，保通关 |

**W7 是三个里最重要的。** 如果那时手感不对，后面 13 周全是白做 ——
这跟"手上有个能跑的东西再往上加"是同一个道理。

## 9. 立刻可以开始的三件事

1. **建项目骨架**：目录结构 + Git + `.gitignore` / `.gitattributes`
2. **写 `FeelConfig` + 调参面板**（W3 提前，因为它解锁后面一切）
3. **实现移动**：用之前那份 `feel-spec-deadcells.md` 里的数值做起点

> 关键数值速查（来自手感规格）：
> 重力 `682.7` / 跳跃初速 `256.0` / 土狼 `0.10s` / 跳跃缓冲 `0.10s`
> 最大速度 `165` / 加速度 `1650` / 转身加速度 `2200` / 减速度 `1150`
