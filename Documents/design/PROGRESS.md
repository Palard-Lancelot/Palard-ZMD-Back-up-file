**过程中发现并修正的问题**（重要，记录备查）：

1. **feel-spec 公式勘误**：跳跃初速应为 `v₀ = 4h/t = 256`，
   原文档误写 `2h/t = 128`（漏因子 2），会得到 12px 高度 / 0.375s 滞空。
   重力 682.7 本身正确。**已同步修正 `feel-spec-deadcells.md` 与 `plan-20weeks-solo.md`**
2. **GDScript 陷阱**：`class_name` 全局注册与 `preload()` 混用
   → 首帧报 `Could not find type FeelConfig`。改用 `Resource` + 显式 cast
3. **类型推断陷阱**：变量声明为 `Resource` 时，其方法返回值无法推断
   → 必须写 `var x: Array = obj.method()`
4. **快捷键不一致**：键码 `4194332` 实际是 **F1** 而非 F11，已统一
5. **调参面板被放到屏幕外**（从运行截图发现）：
   - 原因：用 `MarginContainer` + `set_anchors_preset` 定位，
     而 **CanvasLayer 没有尺寸，锚点会解析为 0**
   - 修正：直接把 `PanelContainer` 锚定到右侧（`anchor_left/right = 1.0` + offset）
   - 同时改为 `visible = OS.is_debug_build()` → 调试时默认展开，导出后默认隐藏
   - 📌 **教训**：CanvasLayer 上的 UI 不要依赖 `set_anchors_preset`，直接设 anchor + offset

> 💡 **这几条 GDScript / Godot 陷阱建议记住**，后面写玩家状态机时会反复遇到。

**过程中修正的问题**：

6. **出生点选在平台正下方**（自动化测试暴露）：
   - 原 `SPAWN_POSITION = (140, 0)`，虽然头顶间隙够（14px），
     但玩家站在 PlatformA 正下方，**视觉上像被钉住**，且首次下落测试
     被天花板接住（撞到 Ceiling 而非 Ground）
   - 修正：出生点移到 `(225, 0)`；自动化测试改用真正空旷的列 `x=330`
   - 📌 **教训**：灰盒场景的"空旷列"要显式留出来，否则测试会撞到意料外的碰撞体

7. **调参面板三处观感问题**（从游戏截图发现）：
   - 面板在右中位置挡住游戏主体 → 移到**左上角**
   - 宽度 300 在 480 宽视口下占 **60%** → 缩到 150（约 31%）
   - 出现垃圾分组 **"— Resource"** → 原因是脚本的类描述被当成
     `PROPERTY_USAGE_CATEGORY`，需显式过滤
   - 默认改为隐藏（先让玩家纯感受手感，F1 再调参）

8. **`boot.gd` 的 headless 自检会干扰自动化测试**：
   - 测试脚本以 `boot.tscn` 为依赖加载，结果 boot 的
     `if DisplayServer.get_name() == "headless": get_tree().quit()`
     **提前结束整个 SceneTree**，测试跑不到断言阶段
   - 修正：新增 `DSH_SKIP_BOOT_QUIT=1` 环境变量开关

**已知偏差（可接受，暂不修）**：
- 跳跃峰值 46px 比理论 48px 低约 **4%**。原因是 Euler 离散积分在上升段
  每帧多算一次重力，45 帧累计约 2px。肉眼看不出，等调参阶段再决定是否用
  半重力修正项。

### 🔴 0.13 是 v1.2 之后的新增验证项

**为什么值得先做：**

```
v1.2 把"每层单向推进"改成了"层内连通可回退"
→ 生成器需要保证：层内连通 + 有回退路径 + 有捷径
→ 如果做不出来，就要退回"单向推进"，第 2/3/5 节需返工
```

**验证内容（纯命令行即可，不需要 Godot 渲染）：**

| 验证项 | 通过标准 |
|---|---|
| 能生成本层连通图 | 输出一张有房间节点与连接边的图 |
| 连通性检查 | **并查集**判定：任意房间都能走回本层出口 |
| 出口可达 | 入口 → 出口必有路径，且**不强制清空全图** |
| 无孤立房间 | 不存在玩家到不了的房间 |
| 捷径生成 | 层内至少 1–2 条捷径，缩短回退路程 |
| 规模可控 | 房间数落在 12–20 间 |

> 💡 **建议用 Python/GDScript 写纯算法原型**，不碰引擎。
> **1 周验证，避免 19 个月后才发现方向错误。**
> 注意：这里**不需要**图论级可解性校验（那是银河城才有的问题），**并查集足够**。
